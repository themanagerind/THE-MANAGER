THE MANAGER - Surat Societies and Login Details

Live site: https://frontend-production-611e.up.railway.app/login  |  Repo: github.com/themanagerind/THE-MANAGER

1. How login works

  • Login is Mobile number + OTP only. There are no passwords in this app.
  • Steps: enter the 10-digit mobile on /login → a 6-digit OTP is sent by SMS (Twilio) → enter the OTP. The OTP expires in 5 minutes. Max 5 OTP requests per hour per number, and 60 seconds between requests.
  • If one mobile belongs to more than one account (e.g. several societies), the app asks which account to open.
  • In development mode the OTP is shown on screen. In production it is only sent by SMS.

2. Platform Owner

  • The Platform Owner manages all societies. Their pages are: Societies, Reports, Change Admin, Society Mapping.
  • The account is created at deploy time from the Railway variable SEED_PLATFORM_OWNER_MOBILE (name from SEED_PLATFORM_OWNER_NAME), by backend/entrypoint.sh.
  • Login: that mobile number + OTP. The actual number is stored in your Railway variables; it is not in the code, so it is not listed here.
  • Platform Owner sessions expire after 12 hours.

3. The login problem and the fix

  • Cause: before the merge, main only logged the OTP (mock SMS). In production the OTP is not returned to the browser, so nobody could receive a code.
  • Fix (merged to main, commit 54a6424): OTPs are now sent through Twilio. It needs these Railway variables on the backend service: TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, TWILIO_FROM_NUMBER (+17372508034), ENVIRONMENT=production.
  • Not yet tested on the live site.
Twilio trial limit: a trial account can only send SMS to numbers verified in the Twilio console. Other users will not receive OTPs until the account is upgraded. A US sender number may also be blocked or delayed for Indian mobiles.

5. How to create them (seed script)

  • Script: backend/scripts/seed_surat_societies.py (merged to main). Each society is created ACTIVE with one ACTIVE Admin. It is safe to run twice.
  • Run against the production database (from the backend folder, with the production DATABASE_URL set), with real numbers in society order:

python -m scripts.seed_surat_societies --mobiles 98xxxxxx01,98xxxxxx02, ... (20 numbers)

  • Without --mobiles it uses the placeholder numbers above.
  • With Twilio on a trial account, verify each real number in the Twilio console first.
  • The script has not been run or tested yet (Python is not installed on the development machine).

6. Security reminders

  • The Twilio Auth Token was shared in chat. Regenerate it in the Twilio console and put the new one only in Railway variables.
  • Set a strong JWT_SECRET_KEY and ECOM_STORE_API_KEY in Railway; the example values must not be used in production.
